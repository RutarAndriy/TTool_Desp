TTool_Desp - це програма для локалізації гри "Desperados: Wanted Dead or Alive",<br>
головною метою створення цієї програми був переклад гри українською мовою

На даний момент програма вміє розпаковувати та запаковувати назад ігрові шрифти (\*.fnt), а також ігрові карти (\*.map) та ігрові логотипи (\*.sxt)

У папці `tools` є утиліта `AssetEditor.zip` (автор YetiWizard), яка дозволяє редагувати ігрові ресурси (\*.res), в яких містяться ігрові тексти та зображення
