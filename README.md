# TTool_Desp
TTool_Desp - це програма для локалізації гри "Desperados: Wanted Dead or Alive",<br/>
головною метою створення цієї програми був переклад гри українською мовою

На даний момент програма вміє розпаковувати та запаковувати назад ігрові шрифти (*fnt файли)

У папці `tools` є утиліта `AssetEditor.zip` (автор YetiWizard), яка дозволяє редагувати ігрові ресурси, зокрема *.res файли, в яких містяться тексти до гри
